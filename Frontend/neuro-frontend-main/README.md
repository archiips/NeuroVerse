# NeuroVerse Frontend

React frontend for the NeuroVerse neuroscience data exploration platform.

## Features

- **5,770+ Datasets**: Browse NDA data structures with smart filtering
- **Category Filters**: Clinical Assessments, Cognitive Tasks, Mental Health, etc.
- **Search**: Real-time dataset search
- **3D Visualizations**: Interactive Plotly charts for demographics
- **Responsive Design**: Mobile-friendly Tailwind CSS styling
- **Pagination**: Efficient browsing with page numbers

## Tech Stack

- React 18
- React Router v6
- Plotly.js (3D charts)
- Axios (HTTP client)
- Tailwind CSS
- Vite (Build tool)

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
